## 📝 三步快速开始

### 方法 A：使用自动化脚本（推荐）

```bash
cd /Users/hujinhui/project/sb
bash 使用GitHub在线编译.sh
```

脚本会引导你完成：
1. 输入 GitHub 仓库地址
2. 配置远程仓库
3. 推送代码到 GitHub
4. 获取后续步骤指引

### 方法 B：手动操作

#### 步骤 1：创建 GitHub 仓库

1. 访问：https://github.com/new
2. 填写仓库名称（例如：android-captcha-solver）
3. 选择公开或私有
4. **不要**勾选 "Initialize this repository with a README"
5. 点击 "Create repository"

#### 步骤 2：推送代码到 GitHub

```bash
cd /Users/hujinhui/project/sb

# 添加 GitHub 远程仓库（替换成你的仓库地址）
git remote add github https://github.com/你的用户名/仓库名.git

# 提交更改
git add .
git commit -m "添加 GitHub Actions 在线编译配置"

# 推送到 GitHub
git push github master
```

**注意事项：**
- 首次推送可能需要输入 GitHub 用户名和密码
- 建议使用 Personal Access Token 代替密码
- Token 创建地址：https://github.com/settings/tokens

#### 步骤 3：触发编译并下载 APK

1. 访问你的 GitHub 仓库
2. 点击顶部的 **Actions** 标签
3. 如果看到提示，点击 **"I understand my workflows, go ahead and enable them"**
4. 点击左侧的 **"Android CI - 编译 APK"**
5. 点击右侧的 **"Run workflow"** 按钮
6. 选择分支（master），点击绿色的 **"Run workflow"**
7. 等待编译完成（约 5-10 分钟，可以看到实时日志）
8. 编译成功后，滚动到页面底部
9. 在 **Artifacts** 部分，点击 **app-debug** 下载
10. 解压下载的 zip 文件，得到 `app-debug.apk`

## 🎁 其他在线编译方案

```bash

# 一键编译
cd /Users/hujinhui/project/sb
docker run --rm -v "$PWD":/project -w /project/AndroidCaptchaSolver \
  mingc/android-build-box:latest \
```

## 🆘 常见问题

### Q1: GitHub Actions 提示 "Workflows aren't being run on this forked repository"

A: 进入 Actions 页面，点击绿色按钮启用工作流。

### Q2: 推送时提示需要认证

A: 需要配置 Git 凭据：
```bash
# 方法 1：使用凭据管理器
git config --global credential.helper osxkeychain

# 方法 2：使用 Personal Access Token
# 在 https://github.com/settings/tokens 创建 Token
# 推送时用 Token 代替密码
```

### Q3: 编译失败怎么办？

A: 
1. 查看 Actions 页面的错误日志
2. 尝试使用 SDK 33 工作流
3. 检查 build.gradle 配置是否正确

### Q4: 下载的是 zip 文件？

A: 是的，GitHub Actions 的 Artifacts 会被打包成 zip，解压后就是 APK 文件。
