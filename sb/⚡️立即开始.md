## 🚀 三步完成编译（最快 15 分钟）

### 第一步：运行自动化脚本

在终端中执行：

```bash
cd /Users/hujinhui/project/sb
bash 使用GitHub在线编译.sh
```

脚本会提示你：
1. 输入 GitHub 仓库地址（需要先在 GitHub 创建仓库）
2. 自动配置 Git 远程仓库
3. 推送代码到 GitHub

### 第二步：创建 GitHub 仓库

**如果还没有 GitHub 仓库：**

1. 打开浏览器，访问：https://github.com/new
2. 填写：
   - **Repository name**: `android-captcha-solver`（或其他名称）
   - **Description**: Android 验证码识别助手（可选）
   - **Public** 或 **Private**: 任选（推荐 Private）
   - ⚠️ **不要**勾选 "Add a README file"
3. 点击 **"Create repository"**
4. 复制仓库地址（例如：`https://github.com/你的用户名/android-captcha-solver.git`）
5. 回到终端，粘贴到脚本提示中

### 第三步：在 GitHub Actions 触发编译

1. 访问你的 GitHub 仓库页面
2. 点击顶部的 **"Actions"** 标签
3. 如果看到提示，点击 **"I understand my workflows, go ahead and enable them"**
4. 点击左侧的 **"Android CI - 编译 APK"**
5. 点击右上角的 **"Run workflow"** 按钮
6. 保持默认选择（master 分支），点击绿色的 **"Run workflow"**
7. 等待 5-10 分钟，直到显示绿色 ✅
8. 滚动到页面底部，在 **"Artifacts"** 部分点击 **"app-debug"** 下载
9. 解压下载的 ZIP 文件，得到 `app-debug.apk`

### 方法 1：ADB 安装（推荐）

## ⚠️ 常见问题速查

### Q: 我没有 GitHub 账号怎么办？

**A:** 注册一个：
1. 访问 https://github.com/signup
2. 填写邮箱、密码、用户名
3. 验证邮箱
4. 免费账号即可使用 Actions

### Q: 推送时提示需要密码？

**A:** 使用 Personal Access Token：
1. 访问 https://github.com/settings/tokens
2. 点击 "Generate new token (classic)"
3. 勾选 `repo` 权限
4. 复制生成的 Token
5. 推送时用 Token 代替密码

### Q: Actions 页面看不到工作流？

**A:** 可能需要：
1. 刷新页面
2. 确认代码已推送成功
3. 检查 `.github/workflows/` 目录是否存在
4. 点击 "I understand..." 启用工作流

### Q: 编译失败了怎么办？

**A:** 尝试备用方案：
1. 在 Actions 页面，选择 "Android CI - 使用 SDK 33 编译"
2. 点击 "Run workflow" 手动触发
3. 查看错误日志定位问题

### Q: 能用其他 Git 平台吗？

**A:** 可以：
- GitLab: 支持类似的 CI/CD
- Gitea: 需要配置 Gitea Actions
- 详见 `在线编译指南.md`
