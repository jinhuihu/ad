## 🎯 推荐使用顺序

**理由：**
1. 速度最快（5-10 分钟）
2. 最简单（只需推送代码）
3. 最可靠（GitHub 官方服务）
4. 可重复使用（以后每次推送都自动编译）

**步骤：**
```bash
# 1. 创建 GitHub 仓库
# 访问 https://github.com/new

# 2. 运行自动化脚本
cd /Users/hujinhui/project/sb
bash 使用GitHub在线编译.sh

# 3. 在 GitHub Actions 页面触发编译

# 4. 下载编译好的 APK
```

### 备选：修复本地 SDK

**适用场景：**
- 需要频繁修改代码并测试
- 网络条件好
- 希望离线编译

**步骤：**
1. 打开 Android Studio
2. Tools → SDK Manager
3. 卸载并重新安装 Android API 36
4. 运行 `bash 快速编译.sh`
